# Approximation-fun-1d

Программа для визуализации аппроксимации функций одной переменной с графическим интерфейсом на Qt.

Реализованы два метода аппроксимации: **полиномы Чебышёва** и **кубические сплайны**. Поддерживается моделирование погрешности измерений, масштабирование графика и переключение между тестовыми функциями.

> Вариант: 5 и 35

## Методы аппроксимации

### Метод 1 — Полиномы Чебышёва (`method_1.cpp`)

Аппроксимация функции разложением по полиномам Чебышёва первого рода. Узлы интерполяции выбираются в нулях полиномов Чебышёва, коэффициенты вычисляются по формулам дискретного разложения. Ограничение: работает при `n < 50`.

### Метод 2 — Кубическая сплайн-интерполяция (`method_2.cpp`)

Построение кусочно-кубического полинома (эрмитова сплайна) на равномерной сетке. Коэффициенты находятся путём решения трёхдиагональной СЛАУ методом прогонки (Гаусса). Работает при любом `n`.

## Тестовые функции

| k | f(x)              | Описание                |
|---|--------------------|-------------------------|
| 0 | 1                  | Константа               |
| 1 | x                  | Линейная                |
| 2 | x²                 | Квадратичная            |
| 3 | x³                 | Кубическая              |
| 4 | x⁴                 | Четвёртой степени       |
| 5 | eˣ                 | Экспонента              |
| 6 | 1 / (25x² + 1)    | Функция Рунге           |

Функция Рунге (k = 6) — классический пример для демонстрации проблем полиномиальной интерполяции на равномерной сетке.

## Зависимости

- Компилятор C++ с поддержкой C++11 или выше
- Qt 5 или Qt 6 (модуль `Widgets`)
- `qmake`

## Сборка и запуск

```bash
qmake my_graph.pro
make
./my_graph a b n k
```

Параметры командной строки:

| Параметр | Описание                          |
|----------|-----------------------------------|
| `a`      | Левая граница отрезка             |
| `b`      | Правая граница отрезка            |
| `n`      | Количество узлов интерполяции     |
| `k`      | Номер тестовой функции (0–6)      |

Пример:

```bash
./my_graph -1 1 10 6
```

Аппроксимация функции Рунге на отрезке [−1, 1] с 10 узлами.

## Управление

| Клавиша  | Действие                                        |
|----------|-------------------------------------------------|
| `0`      | Сменить тестовую функцию                        |
| `1`      | Перерисовать график                             |
| `2`      | Увеличить масштаб (zoom in)                     |
| `3`      | Уменьшить масштаб (zoom out)                    |
| `4`      | Увеличить число узлов вдвое (n × 2)             |
| `5`      | Уменьшить число узлов вдвое (n / 2)             |
| `6`      | Моделировать погрешность: +f(x)/10              |
| `7`      | Моделировать погрешность: −f(x)/10              |
| `Ctrl+X` | Выход                                           |
